# 💰 Budget Tracker Application

A clean, accessible web-based **Budget Tracker** built to help users manage their income and track daily expenses effectively. This project is part of the Week 2 Web Development curriculum.

## 🚀 Features Built (Week 2 Updates)
* **Interactive Expense Table:** Organized layout displaying Name, Amount, Category, and Date with distinct alternating background rows and visual hover highlights.
* **Upgraded Data Input Form:** A fully wrapped HTML form containing validation parameters, custom element tracking IDs, and an intuitive `<select>` dropdown menu for item categories.
* **Embedded Multimedia:** Integrated custom logo branding elements alongside a responsive embedded YouTube budgeting tutorial resource frame.
* **Collapsible Help Directory:** An interactive `<details>` accordion block explaining fundamental application operations.

## 🛠️ Technologies Used
* **HTML5:** Semantic architecture (`<table>`, `<form>`, `<details>`, `<iframe>`)
* **CSS3:** Advanced styling implementations (Direct child combinators, structural positional pseudo-classes, interactive state transitions)

## 📁 How to Run the Project
1. Clone or download this project folder to your local machine.
2. Ensure `index.html`, `style.css`, and your logo image file are located in the same directory.
3. Open `index.html` in any modern web browser (or run it via the VS Code *Live Server* extension at `http://127.0.0.1:5500`).
